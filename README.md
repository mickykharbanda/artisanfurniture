# Artisan Furniture & Homedecor Client Portal

## PDF Storage Instructions

1. Create a `pdfs` directory in the root of the repository if it doesn't exist.
2. When uploading PDFs through the client portal:
   - The PDF will be downloaded to your computer
   - Save it in the `pdfs` directory with the correct category name (e.g., `sofa.pdf`, `bed.pdf`, etc.)
   - Commit and push the PDF to GitHub
   - The PDF will then be available for viewing in the portal

## PDF Categories

- side-table.pdf
- center-table.pdf

- artifacts.pdf
